# 000167: fix/session-reload-flicker

## Intent

Eliminate constant session content reloads, `SIGWINCH` redraws, and top-to-bottom scroll animations on session switch, input, and snapshot refresh across the web and native Flutter clients (`devlog/plans/000167-01-session-reload-flicker.md`).

## What Changed

- `2026-10-18T22:26-0700` `flutter/triage_client/lib/main.dart`: Gate unused `package:xterm` write/clear/resize listeners in `SessionVm` on `!kIsWeb`. Seed `hostSizeCols`/`hostSizeRows` in `_loadDaemonSession` and preserve them with `??=` in `_loadDaemonSessionInto`. Add `_fitOrReclaimActiveSessionOnWeb()` and use it in `_selectSession` and `_connectWebSocket` post-frame callbacks so web session switches and connects call `session.terminalController.fit()` when the host size already matches this device's fit, only calling `_refitActiveSession()` (`rows - 1` to `rows` jiggle) when `session.hostSizeDriftedFromOwnFit || _selectedSessionGridDriftedFromHost()` is true. Skip the duplicate standalone `Observer` lease-probe `attachSession` in `_selectSession` when `session.hasFitted` is true (since `_refreshSessionSnapshot(includeHistory: false)` immediately performs the same probe and updates `hasInputLease`, failing safe to `false` on error under `!_isStale(owningGeneration)`). Capture `prevExited` before mutating `session.isExited` and skip `setState` in `_applySnapshotToSession` when no UI-visible field changed.
- `2026-10-18T22:26-0700` `flutter/triage_client/lib/widgets/terminal_pane_web.dart`: Suppress scroll saves across cached-container remounts in `initState` with a monotonic deadline (`_suppressScrollSaveUntil`), restore scroll position in the post-frame callback after DOM attachment, guard scroll-position saves in `_unbindContainerEvents()` when `_suppressScrollSave` or a pending clear/write is active, and compute `wasAtBottom` in `_onFit()` from `!_sessionSavedViewportY.containsKey(_sanitizedId)` so transient DOM `scrollTop == 0` resets on `HtmlElementView` re-insertion cannot poison `_sessionSavedViewportY` with line `0`. Coalesce per-session `onClear` and `onWrite` chunks into a single `term.write` call per turn, reconcile grid dimensions before flushing history replays, guard `term.write` completion callbacks with a monotonic `_scrollRestoreGeneration` counter, and mask `_terminalWrapper` (`opacity: 0` with a 250ms safety timer backstop) across clear+replay writes until `term.write`'s completion callback restores the target scroll position.
- `2026-10-18T22:26-0700` `flutter/triage_client/test/widget_test.dart`: Add regression test verifying that re-selecting an already-fitted subscribed session issues a single `attachSession` probe without clearing the terminal or bumping `focusCursorRevision` on a no-op metadata refresh, and resets `hasInputLease` to `false` if the refresh fails.
- `2026-10-18T22:26-0700` `devlog/plans/000167-01-session-reload-flicker.md`: Record the design plan for eliminating session reload flicker and top-to-bottom scroll jumps.

## Decisions

- `2026-10-18T22:10-0700` Gate automatic web post-frame refits in `_selectSession` and `_connectWebSocket` on `session.hostSizeDriftedFromOwnFit || _selectedSessionGridDriftedFromHost()`, falling back to `session.terminalController.fit()` when sizes already agree. Calling `_refitActiveSession()` unconditionally sent `rows - 1` followed 60ms later by `rows` (`SIGWINCH` x 2) on every rail switch, forcing full-screen TUIs to clear and redraw from top to bottom.
- `2026-10-18T22:10-0700` Collapse the duplicate `Observer` `attachSession` RPC in `_selectSession` when `session.hasFitted && subscribed` (letting `_refreshSessionSnapshot(includeHistory: false)` own both lease resync and metadata refresh), and skip `setState` in `_applySnapshotToSession` when no UI-visible field changed.
- `2026-10-18T22:10-0700` On web (`terminal_pane_web.dart`), determine `wasAtBottom` in `_onFit()` from `!_sessionSavedViewportY.containsKey(_sanitizedId)` and suppress scroll saves across cached-container remounts so the browser's DOM re-insertion `scrollTop = 0` reset cannot poison `_sessionSavedViewportY` with line `0`.
- `2026-10-18T22:10-0700` Coalesce web `onClear` and `onWrite` chunks per session into a single `term.write` call and mask `_terminalWrapper` with `opacity: 0` (preserving `.xterm-helper-textarea` focus) during full and paged history replays until `term.write`'s completion callback finishes parsing and restores the target scroll line.
- `2026-10-18T22:22-0700` Leave `terminal_pane_stub.dart`'s `_scrollToCursor` on its post-frame callback rather than adding a synchronous pre-layout `jumpTo`: `RenderTerminal.performLayout()` only updates `ScrollPosition.maxScrollExtent` during the layout phase, so jumping synchronously after `terminal.write` would read the previous frame's `maxScrollExtent` and could prematurely clear a scrolled-up anchor.
