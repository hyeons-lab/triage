## Decisions

- 2026-11-11T00:28-0800 Deliver the end-to-end architecture on a single branch/PR with lockstep daemon/client capability: retire `xterm2`, `xterm.js`, client-side `triage-term` FFI, and client VT byte-stream replay together, and surface an explicit daemon upgrade required message if the client connects to an older `triaged` daemon that predates `SyncTerminal` / `FetchTerminalRows`.
- 2026-11-11T00:28-0800 Move `triage-term` cell packing and sideband DEC mode tracking into safe Rust (`rlib` consumed directly by `triaged`): `triaged` already maintains a canonical `tattoy_wezterm_term::Terminal` and `ScrollbackJournal` per session, so diffing `line.changed_since(baseline_seqno)` on the server eliminates client VT re-emulation, turns `crates/triage-term` into 100% safe Rust without `extern "C"` FFI exports, and removes Android NDK / CI client Rust cross-compilation.
- 2026-11-11T00:28-0800 Compress packed `TCG1` binary cell frames and scrollback pages with zlib/deflate (`flate2` in `triage-core`/`triaged` and `dart:io` `zlib` / `package:archive` `ZLibDecoder` in `triage_client`): both dependencies already ship in the workspace and work identically on native Dart VM and `dart2js`/Wasm without adding native or WASM decoder blobs, while compressing sparse 4-word cell arrays by 10-30x.
- 2026-11-11T00:28-0800 Unify `Terminal` in-memory scrollback (`<= 3,500` reflowed rows) and on-disk `ScrollbackJournal` (`<= 210,000` archived SGR rows) behind a single virtual row coordinate space `[0 .. total_scrollback_rows)` using monotonic journal sequence numbers (`first_retained_seq`, `next_seq`), `journal_clear_floor` (advanced on `CSI 3J`), and `mirrored_journal_records`: this preserves existing `ScrollbackJournal` retention and `CSI 3J` persistence guarantees while preventing seam duplicates or gaps across live scrolling, width reflows, `CSI 3J` clears, and cold/handover restores.
- 2026-11-11T00:28-0800 Pace live WebSocket terminal diffs with per-subscriber `ClientSyncBaseline` + `AckTerminalSync` windowing (`MAX_IN_FLIGHT_FRAMES = 2`) and server-side DEC Mode 2026 coalescing: fast links stream dirty-row diffs at up to 100 Hz, while slow or high-RTT links collapse intermediate TUI redraws into a single latest diff instead of queueing stale frames in TCP buffers.

## Issues

- 2026-11-11T01:05-0800 DEC `?9` (X10 press-only mouse mode) and DEC `?1000` (VT200 press/release/wheel mouse mode) initially mapped to the same wire code: separated into `mouse_mode = 1` (`?9`), `2` (`?1000`), `3` (`?1002`), and `4` (`?1003`) in both `crates/triage-term` and `terminal_mouse_encoder.dart`.
- 2026-11-11T02:20-0800 `TerminalPane._snapToBottom` captured a pre-layout scroll anchor before `RenderTerminalGrid.performLayout` updated `maxScrollExtent`, leaving `TerminalGridView` unpinned after output bursts: cleared `_scrollAnchor` on snap-to-bottom so `stickToBottom` pins synchronously during layout.
- 2026-11-11T02:48-0800 `SessionVm(isExited: true)` called `markExited()` before lazy `_terminal` creation, leaving `terminal.cursorVisible` true on cold exited-session view models: propagated `!isExited` cursor visibility inside `_createTerminal()`.
- 2026-11-11T03:05-0800 `_selectSession` scheduled a redundant post-frame delta `_refreshSessionSnapshot` even when `!subscribed` had already launched `_resubscribeAndRefreshHistory`: gated the post-frame fallback refresh on `sid == null || subscribed`.
- 2026-11-11T08:01-0800 `libc::openpty` in `handover_terminal_modes_round_trip` passed `&mut ws`, triggering `clippy::unnecessary_mut_passed` on Linux (`*const winsize` on glibc vs `*mut winsize` on Darwin): cast `&ws as *const libc::winsize as *mut libc::winsize` matching the adjacent handover test.
- 2026-11-11T08:39-0800 `handover_preserves_sideband_terminal_modes` in `crates/triaged/src/session.rs` lacked `#[cfg(unix)]`, failing Windows test compilation (`libc::openpty` and `spawn_adopted_pty_runtime` are Unix-only): added `#[cfg(unix)]` matching the adjacent `spawn_adopted_pty_runtime` tests.
- 2026-11-12T18:28-0800 Narrowing terminal width split previously journaled scrollback rows into physical continuation rows with zero per-row count, causing later eviction to persist duplicate history lines: packed sticky `ROW_ALREADY_JOURNALED_BIT` into `OutputState::row_journal_counts` across split and merge reflows, and persisted `scrollback.meta` on segment retention/rebase so reopen recovers `first_retained_seq` without phantom blank prefixes.
- 2026-11-12T18:28-0800 Defaulting `TerminalSelectionRange.reflowGen` to `0` broke unpinned callers once `buffer.reflowGen` advanced, and reading `HardwareKeyboard.instance.lockModesEnabled` unconditionally threw in headless unit tests: made `reflowGen` nullable (`int?`, passed by interactive selection sites) and gated CapsLock lookup behind `kittyDisambiguate` with an uninitialized-binding fallback.
