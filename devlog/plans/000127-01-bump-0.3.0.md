# 000127-01 bump 0.3.0

## Thinking

PR 139 was originally created as `chore(release): bump to 0.2.2` after the 0.2.1
release when only #135, #136, and #138 had landed. Since then, major feature and
stability work landed on `origin/main`:
- #143: Approval Judge resident model, deterministic rule tables, `triage-hook`
  shim, TUI controls, Flutter settings tab and audit stream.
- #144: Zero-downtime SIGTERM rescue daemon handover, preventing session destruction
  on supervisor stops/upgrades, lock scope optimization, and fd leak prevention.
- #145: Synchronized Output mode 2026 support, eliminating cursor jumping, with
  hardened web terminal focus and scroll pinning.
- #142: Raw newline preservation, terminal query auto-response filtering (CPR, DA,
  DSR, Kitty, OSC, DECRPM), unified xterm.js onData keyboard handling.
- #140 & #141: Unicode 11 addon activation in xterm.js with `allowProposedApi`
  for proper emoji and CLI spinner rendering.

On `origin/main`, the version has already moved to `0.3.0` across `VERSION`,
`Cargo.toml`, and `flutter/triage_client/pubspec.yaml`. The maximum version
published on crates.io is 0.2.1 for all existing crates, and `triage-hook` is
new (unpublished). Thus, PR 139 represents the 0.3.0 release PR.

The task is to:
1. Rebase PR 139 branch onto `origin/main`.
2. Add a comprehensive `CHANGELOG.md` detailing the 0.3.0 release changes and
   previous versions.
3. Update repository READMEs across root and all crates (`triaged`, `triage`,
   `triage-hook`, `triage-core`, `triage-transport-ws`, `triage-mcp`,
   `flutter/triage_client`) to document the new features (Approval Judge,
   `triage-hook`, configuration, `triaged reload` & SIGTERM rescue, Synchronized
   Output mode 2026, Unicode 11, etc.).
4. Add a dedicated `docs/configuration.md` reference guide.
5. Verify everything with the full CI suite (`bump-version.sh --check`,
   `cargo fmt`, `cargo clippy`, `cargo doc`, `cargo test`).
6. Update the PR 139 title and description on GitHub.
